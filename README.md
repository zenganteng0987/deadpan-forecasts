A deadpan TV weather forecast for Port Quibble, a city that does not exist: sunny spells at 23°C, except the sea briefly stands up at noon to stretch, so beachgoers should hold their hats.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the one-line forecast to `out/entry.txt` (or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset).
